================================

نسخه فعلی پروژه: 1.0.1 (versionCode 2)
حداقل اندروید: Android 6.0 (API 23)
هدف اندروید: API 35

امکانات فعلی
- مدیریت مشتریان، قرض‌ها، پرداخت‌ها و تاریخچه حساب
- ذخیره محلی اطلاعات و پشتیبان خودکار در حافظه خصوصی برنامه
- ساخت فایل واقعی JSON برای انتقال اطلاعات به گوشی دیگر
- انتخاب فایل JSON و بازیابی پشتیبان در Android WebView
- اصلاح فرم ویرایش مشتری تا اطلاعات قبلی هنگام باز شدن فرم پاک نشود
- افزودن شناسه جایگزین برای سازگاری بهتر با WebViewهای قدیمی‌تر
- نام فروشگاه در راه‌اندازی نخست قابل تعیین است
- بخش درباره برنامه همراه عکس صاحب برنامه
- بدون مجوز اینترنت؛ اطلاعات مشتریان به سرور ارسال نمی‌شود

ساخت نسخه آزمایشی APK
1. پروژه را در Android Studio باز کنید.
2. از JDK 17 و Android SDK Platform 35 استفاده کنید.
3. اجازه دهید Gradle Sync کامل شود.
4. از Build > Build APK(s) نسخه آزمایشی را بسازید.

ساخت نسخه انتشار Google Play
برای امنیت، کلید امضای انتشار نباید داخل ZIP یا GitHub قرار داده شود.
در GitHub repository بخش Settings > Secrets and variables > Actions این چهار Secret را بسازید:
- ANDROID_KEYSTORE_BASE64: محتوای فایل keystore به صورت Base64
- ANDROID_KEY_ALIAS: نام alias کلید
- ANDROID_KEY_PASSWORD: رمز کلید
- ANDROID_STORE_PASSWORD: رمز keystore
سپس از Actions، workflow را با گزینه Run workflow اجرا کنید.
فایل AAB امضاشده در Artifact با نام Khyber-Supermarket-Play-Store-AAB قرار می‌گیرد.
کلید keystore و رمزهای آن را در چند جای امن نگهداری کنید و گم نکنید.

مواردی که پیش از نشر واقعی باید انجام و آزمایش شوند
- اجرای APK روی گوشی واقعی و آزمایش ثبت/ویرایش مشتری، قرض، پرداخت و تاریخچه
- آزمایش خروجی و بازیابی فایل پشتیبان روی یک گوشی دیگر
- بررسی نمایش درست زبان و اعداد روی دستگاه‌های مختلف
- تکمیل ترجمه پشتو؛ دکمه فعلی فقط پیام اطلاع‌رسانی نشان می‌دهد
- تهیه و انتشار صفحه سیاست حریم خصوصی و تکمیل فرم Data safety در Play Console
- تهیه تصاویر واقعی از برنامه و متن معرفی فارسی/دری و در صورت نیاز زبان‌های دیگر
- تکمیل تست داخلی/بسته‌بندی‌شده Play Console و رفع هر اخطار احتمالی

وضعیت فعلی
این ZIP سورس پروژه است، نه APK یا AAB آماده نصب/انتشار. کد در این محیط با Android SDK و گوشی واقعی کامپایل و آزمایش نشده است.
نسخه نهایی را تا پایان آزمایش‌های واقعی و تکمیل الزامات Play Console منتشر نکنید.
